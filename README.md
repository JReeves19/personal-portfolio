# Jake Reeves | Personal Portfolio

A responsive personal portfolio website for Jake Reeves, a Computer Science student at Clark Atlanta University. The site highlights professional background, projects, experience, education, and contact information.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Responsive navigation with a mobile menu
- Home, About, Projects, Experience, Education, and Contact sections
- Resume links and professional social links
- Responsive layouts for desktop and mobile screens

## Run Locally

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Project Structure

```text
personal-portfolio/
|-- assets/          # Headshot and resume files
|-- index.html       # Page structure and content
|-- mystyle.css      # Site styling and responsive layouts
`-- README.md
```
